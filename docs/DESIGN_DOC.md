# Gem Vanguard — Дизайн-документ и Архитектура

## 1. Концепция
Казуальный пошаговый Match-3 батлер в стиле **Casual Dark Fantasy** для веб-платформы **Poki** (`wasm-web`, Portrait для мобильных и Landscape для десктопа).

## 2. Основные механики
- **Общее поле `7×7`:** игрок и враг ходят по очереди на одной доске. Поддерживаются свайпы и два последовательных клика.
- **Система 1–7 ходов:** количество действий игрока за раунд зависит от прокачки (`1 → 7`), у врагов — от класса и уровня (`1 → 6`).
- **5 стихийных кристаллов:**
  - **Красный (Рубин / Меч)** — Урон отряда 1-го ранга (`×1`).
  - **Жёлтый (Топаз / Молния)** — Урон отряда 2-го ранга (`×2`).
  - **Фиолетовый (Аметист / Пламя)** — Урон отряда 3-го ранга (`×3`).
  - **Зелёный (Изумруд / Крест)** — Лечение HP Командира.
  - **Синий (Сапфир / Щит)** — Накопление Щита поверх HP.
- **Спецкристаллы:** 4 в ряд → Линейный (`line_h`/`line_v`), T/L-форма → Бомба `3×3` (`bomb`), 5 в ряд → Призма (`prism`).
- **Отряды (1–5 воинов) и прокачка как в Clash Royale:**
  - Единое HP Командира + **3 слота отрядов** под Красный, Жёлтый и Фиолетовый цвета (ни один цвет никогда не отключается).
  - Карточки выпадают из сундуков и после онбординга; уровень повышается при наличии копий и **Золота**.
- **Сундуки (4 слота в Хабе):**
  - Деревянный (`1 мин`), Серебряный (`1 час`), Королевский (`24 часа`).
  - **Алмазы** ускоряют открытие сундуков раньше времени и позволяют разблокировать закрытые карточки отрядов.
- **Престиж и режимы:**
  - **Престиж** растёт при победах и снижается при поражениях.
  - **Кампания** (12 этапов, 3 биома, боссы, перепрохождение) и **PvP** (подбор противника-бота под текущий Престиж).
  - **Онбординг:** первый запуск сразу открывает обучающий бой 1, после победы даёт сундук и карточки для демонстрации апгрейда отряда в Хабе.

## 3. Структура модулей
- **Логика (`main/modules/`):** `config.lua`, `squads.lua`, `campaign.lua`, `board.lua`, `ai.lua`, `battle.lua`, `progress.lua`, `i18n.lua`, `layout.lua`, `rng.lua`, `poki.lua`, `audio.lua`.
- **Интерфейс (`main/gui/`):** `ui.lua`, `battle_view.lua`, `hub_view.lua`, `map_view.lua`, `shop_view.lua`, `popups.lua`, `game.gui_script`.
- **Ассеты (`tools/`):** `gen_sprites.js` (70 SDF-спрайтов + `game.atlas` + `sprite_sizes.lua`), `gen_font.js` (`main.font`), `gen_sounds.js` (11 WAV + `sounds.go`).

> Примечание: для отладки на время офлайн-генерации в `main/assets/fonts/Nunito-Black.ttf` использован локальный системный кириллический шрифт — перед коммерческой публикацией рекомендуется заменить его на шрифт с открытой лицензией SIL OFL (например, оригинальный `Nunito-Black.ttf`).
